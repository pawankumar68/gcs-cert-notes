## Past Cyberattacks and Their Impact

### Brain Virus (1986)
Created by the Alvi brothers to track illegal copies of medical software.
Shaped the cybersecurity industry by emphasizing the importance of
proactive security measures and dedicated security teams.

### Morris Worm (1988)
Developed by Robert Morris to map the internet.
A flaw caused it to repeatedly reinstall itself, crashing approximately
6,000 computers and resulting in millions of dollars in damage.
Led to the establishment of Computer Emergency Response Teams (CERTs).

These early attacks highlighted the critical need for robust security
strategies and incident response plans.

## Attacks in the Digital Age

### LoveLetter Attack (2000)
Malware that spread rapidly by exploiting human trust through
unsolicited emails. Infected 45 million computers causing over
$10 billion in damage.

### Equifax Data Breach (2017)
Credit reporting agency Equifax suffered a major data breach due to
multiple unaddressed vulnerabilities, compromising over 143 million
customer records.

## Common Attack Types

### Phishing
Use of digital communication to trick people into revealing sensitive data.

| Type | Description |
|------|-------------|
| Business Email Compromise (BEC) | Threat actor sends email seeming from known source to obtain financial advantage |
| Spear Phishing | Targets a specific user or group, email seems to come from trusted source |
| Whaling | Targets company executives |
| Vishing | Exploits electronic voice communication to obtain sensitive data |
| Smishing | Uses text messages to trick victims |

---

### Malware
Software designed to harm devices or networks.

| Type | Description |
|------|-------------|
| Virus | Written code that interferes with computer operations, needs user to transmit |
| Worm | Can duplicate itself across systems without user action |
| Ransomware | Attacker encrypts data and demands money to restore access |
| Spyware | Used to gather and sell information without user knowledge |

---

### Social Engineering
A manipulation technique that exploits human errors.

| Type | Description |
|------|-------------|
| Social Media Phishing | Attacker collects details of target from social media |
| Watering Hole Attack | Attack on a website frequently visited by a group of users |
| USB Baiting | Leaving USB drives intentionally for someone to plug in |

---

### Password Attacks
Attempts to access secure devices or systems.
- **Brute Force** — Trying all possible combinations
- **Rainbow Table** — Using precomputed hash values to crack passwords

### Physical Attacks
Damage to physical environment where attack is deployed.
- Malicious USB Cable
- Malicious Flash Drive
- Card Cloning

### Cryptographic Attacks
Affect secure forms of communication between sender and recipient.
- Birthday Attack
- Collision Attack
- Downgrade Attack

## 8 Security Domains (CISSP)

| # | Domain | Purpose |
|---|--------|---------|
| 1 | Security and Risk Management | Defines security goals, risk mitigation and compliance with law |
| 2 | Asset Security | Protects digital and physical assets |
| 3 | Security Architecture and Engineering | Optimizes data security tools and systems |
| 4 | Communication and Network Security | Manages and secures networks |
| 5 | Identity and Access Management | Keeps data secure by controlling who can access it |
| 6 | Security Assessment and Testing | Conducts security audits and tests |
| 7 | Security Operations | Analyzing and monitoring logs, investigating incidents |
