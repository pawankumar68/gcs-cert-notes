# Module 4 — Cybersecurity Tools and Computing Basics

## Source
Google Cybersecurity Professional Certificate — Foundations of Cybersecurity

---

## Log
A record of events that occur within an organization's systems.
Logs are used by SOC analysts to monitor activity and investigate incidents.

---

## SIEM Tool (Security Information and Event Management)
An application that collects and analyzes log data to monitor
activity across an organization's systems.

Examples:
- **Splunk** — most widely used SIEM in SOC environments
- **Chronicle** — Google's cloud-native SIEM

---

## Playbook
A manual that provides detailed steps for any operational action.
SOC analysts follow playbooks when responding to security incidents
to ensure a consistent and correct response every time.

---

## Network Protocol Analyzer (Packet Sniffer)
A tool designed to capture and analyze data traffic within a network.

Examples:
- **Wireshark** — GUI-based packet analyzer
- **TCPDump** — CLI-based packet analyzer

---

## Antivirus Software
Software used to prevent, detect and eliminate malware and viruses
from a system before they can cause damage.

---

## IDS (Intrusion Detection System)
An application that monitors system activity and alerts on
possible intrusions or suspicious behavior.

---

## Encryption
The process of making data unreadable and difficult to decode
for unauthorized users. Protects sensitive data in transit
and at rest.

---

## Programming in Cybersecurity
Programming is the process of creating a specific set of
instructions for a computer to execute.

Cybersecurity professionals use:
- **Python** — for automation, scripting and security tools
- **SQL** — to access, create and manage databases,
  and to query logs for investigation

---

## Portfolio
A collection of work used by cybersecurity professionals to
demonstrate their security education, skills and knowledge
to potential employers.

Why it is necessary:
- Shows practical skills beyond a resume
- Proves hands-on experience with real tools
- Demonstrates consistency and documentation habits

---

## How This Connects to Real SOC Work
- SIEM tools are used daily to monitor logs and detect threats
- Playbooks guide every incident response action
- Packet sniffers help investigate suspicious network traffic
- Python scripts automate repetitive SOC tasks
- A portfolio is what gets you the interview
